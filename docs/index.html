What it changes.

Each pair is the same screen twice: the palette Android ships with, and the palette the seed above is producing right now.

Any seed, any source

Generate palettes from your wallpaper, pick from basic colors, or dial in an exact hex. Everything previews live before it touches the system.

Sliders that go further

Accent saturation, background saturation, and background lightness, from 0 to 200%, set per light and dark mode in CAM16 color space.

Per-shade overrides

Press any shade in any palette row and set it to whatever you want. The whole system follows, one shade at a time.

Monet styles

Tonal Spot, Vibrant, Expressive, Rainbow, Fruit Salad, Monochrome and more, plus color spec 2021, 2025, or 2026 on supported builds.

Dark mode, properly

Pitch black backgrounds for AMOLED, tinted text, and separate configurations for light and dark mode.

Backup and restore

Sliders, overrides, saved styles: everything you set up exports to a single file and comes back with one import.

The app, as it ships.

Built in Jetpack Compose with Material 3 Expressive. The app previews every change in its own UI before you apply it to the system.

Three ways in. Root gets everything.

Any Android 12+ device with Material You works. Root registers overlays directly; Shizuku and Wireless ADB write the system's theme settings through a shell-privileged helper.

Root

Fabricated overlays register directly with the system's overlay service, so palette changes land instantly. The full engine: sliders, per-shade overrides, pitch black, per-app themes.

Grant root once

Shizuku

No root required. A helper process at shell privilege writes the system's theme customization settings directly.

Start Shizuku after each boot

Wireless ADB

The same shell-privilege path, negotiated on-device over the ADB TLS protocol. Useful where Shizuku isn't installed; no computer needed after pairing.

Questions.

How does it work without root?

Shizuku and Wireless ADB modes run shell commands that write the documented theme_customization_overlay_packages secure setting. It's the same mechanism the stock wallpaper picker uses, with more of its fields filled in.

How does it work with root?

Root mode uses the FabricatedOverlay API to register palette overlays with the system at runtime. Nothing is written to the system partition; removing a theme is the same operation as applying one.

Why doesn't it fully work on OneUI?

OneUI system apps use Samsung's own palette instead of Material You. ColorBlendr's changes reach Google apps and everything else that honors Monet, but not OneUI's system UI.

Why are some features grayed out?

They need either a newer Android version or root. Sliders, per-shade overrides, pitch black, and applying community themes are root-mode features; a badge in the app tells you which is which.

Is sharing a theme anonymous?

Yes. There's no account and no sign-up. Only the palette plus the name and description you type are submitted, and a person reviews every submission before it appears.

How do I uninstall it cleanly?

Turn off the ColorBlendr service in the app's settings, then uninstall and reboot. Your device returns to its stock wallpaper-derived colors.
